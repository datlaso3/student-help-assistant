# Student Help Assistant (concept demo)

A BUS201 Digital Transformation for Business group project at Western Sydney University Vietnam. It demonstrates a proposed help assistant that answers routine student questions from the public MyWSU.vn student guide and drafts a support ticket for anything personal.

Not an official Western Sydney University service. No login, nothing stored. To try it, paste your own Gemini API key from Google AI Studio into the chat; the key stays in the browser tab only.

- `index.html`: full concept page (portal layout with the assistant)
- `widget.html`: assistant only, for embedding in a Google Site

The guide text inside the pages was copied from the public MyWSU.vn guide on 21 October 2026. This repository will be removed after the course.
